# Практична робота №2: Робота з Docker Volumes

У цій роботі було досліджено механізм збереження даних контейнерів за допомогою Docker Volumes на прикладі СУБД PostgreSQL.

## Виконані кроки:
1. Створено незалежний іменований том `pg_data`.
2. Розгорнуто офіційний образ `postgres:16-alpine` з Docker Hub.
3. Монтування тому виконано за шляхом `/var/lib/postgresql/data`, що гарантує збереження бази даних навіть після видалення чи перезапуску контейнера.
4. Порт СУБД `5432` прокинуто на локальну машину.

*Всі використані команди збережено у файлі `commands.bat`.*
